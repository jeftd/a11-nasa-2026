# 06 — Submission Rules That Affect This Project

Source: Space Apps 2026 Project Submission Guide and Participant FAQs (read Nov 14, 2026).
https://www.spaceappschallenge.org/resources/project-submission-guide/

## Deadlines
- Submission opens Saturday **Nov 14, 2026, 9:00 a.m.** local time.
- Submission closes Sunday **Nov 15, 2026, 11:59 p.m.** local time of the Team Owner. Late = not judged.
- Judging afterwards; Global Nominees/Finalists announced December 2026, Global Winners January 2027.

## Data
- **To be eligible for a Global Award, the project must use at least one NASA data source or resource.**
  FIRMS covers this.
- Projects are **not limited** to the challenge's Resources tab: use of Space Agency Partner data is
  encouraged, and other data/tools are allowed, but **every** data source, resource, code library, text and
  image used must be listed on the submission page. Copyrighted material needs permission.
- For non-U.S.-Government sites, follow their data-use terms.

## Language
- Submission page and all linked materials must be in **English**. A video may be spoken in another language
  only with English subtitles; slide decks must be in English.

## Demo
- Either a **video ≤ 30 seconds** or a **slide deck ≤ 7 slides** (including title/intro). Exceeding limits =
  not eligible for Global Judging.
- Must include team name, team members, and the challenge selected; show how NASA/space-agency data make the
  solution possible.
- Publicly accessible link (no password/permission/registration).
- No images, video, audio or likeness of persons under 18.

## Final project link
- Publicly accessible (GitHub repo and/or live website). If hosting a new website, consider requesting a
  FortiGuard Web Filter Classification so judges' networks don't block it.

## Super Intelligence (SI / AI) disclosure
- If SI tools were used: images/videos need a visible watermark; audio needs acknowledgment; **code and data
  must acknowledge SI generation in descriptive text and metadata.** This repo includes that
  acknowledgment in the README.

## Judging criteria
Impact, Creativity, Validity, Relevance, Presentation (details in the 2026 Judging and Awards Guide).
